# Experiments

Copy `template.toml` to a dated file before implementing or evaluating a
performance idea. Fill in the hypothesis, comparator, corpus roles, primary
metric, and stopping rule first. Afterward, append revision IDs and result paths;
do not rewrite the prediction to match the outcome.

Large JSONL results, profiles, solver binaries, and third-party corpora are
ignored or should live in artifact storage. Small manifests and conclusions
belong in version control.
